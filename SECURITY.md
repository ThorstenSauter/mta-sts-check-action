# Security policy

## Supported versions

Only the latest `v1.x.y` release gets security fixes. The `v1` tag always points at it.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ThorstenSauter/mta-sts-check-action/security/advisories/new)
instead. Include the affected version, how to reproduce it, and the impact you expect.

You'll get an answer within a week. Fixes are released as a new patch version, and the advisory is published once the
fix is out.
